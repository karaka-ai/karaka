# DeepSeek Harness legacy corpus

This directory preserves documentation, active decision records, repository workflows, and branding from the pre-Karaka harness. It is historical material: active builds, linting, documentation checks, workspaces, and publication exclude it.

Removed product source remains available through Git history. Frozen Agent Note triplets remain at `.agents/notes/archived/` because their archive policy prohibits moving or editing them.
